# bili-sweep

让 AI agent 每天刷 B 站、只对真正喜欢的视频认真写一条评论、并且不重复的完整执行蓝本。

## 它解决什么

让 AI「刷视频」本身很简单，难的是三件事：

1. **不重复发评论** —— 同一条视频下挂三条一样的话，一眼就是机器人
2. **不说空话** —— 「好视频」「支持」这种评论没有意义，也骗不过人
3. **不搞乱用户的浏览器** —— 开一堆标签页不关，或者把用户自己的页关掉

这个 skill 把三件事都做成了可检查的步骤。

## 核心：发评前四查

| 查什么 | 堵住哪种翻车 |
|---|---|
| 查自己的记录文件 | 同一个视频再来一次 |
| **打开评论区实查本账号** | 换了文案但同一个视频（这条最关键，记录文件挡不住） |
| 查文案唯一性 | 跨视频套模板 |
| 拿不到 rpid / 页面异常就不发 | 拿不准时硬发 |

前三条任一没做，等于把控制权交给运气。

## 六阶段

```
阶段 0  开工准备    标签页快照 + 读人设 + 读查重文件
阶段 1  选方向      优先未刷过的，当天不重刷同一关键词
阶段 2  搜索        取标题/UP/播放量/BV，关键词立即记账
阶段 3  逐个观看    同时最多 1 个视频页，开一个关一个
阶段 4  发评        ★ 四查 → 发送 → 立即记账
阶段 5  写日记      当天段落追加，桌面快照只追加不改历史
阶段 6  收尾        只关自己开的页，汇报四项
```

## 硬约束

- 全程后台静默：不弹窗、不抢焦点、不切前台、不全屏
- 每轮 ≤3 条评论，全天 ≤12 条，**每轮至少 1 条，宁缺毋滥**
- 每条评论间隔 ≥2 秒
- 查重文件只追加，**严禁覆盖 / 重建 / 截断**；发现变短立即停手
- 不泄露使用者任何信息，不提 AI / 脚本 / 自动化，不点站外链接，不参与引战

## 和 tab-hygiene 的关系

标签页收尾这一段单独抽成了 `tab-hygiene` skill —— 因为凡是用浏览器的任务都需要它，不只刷视频。

关键实测结论：**标签页的所有权绑在打开它的那个任务上**。任务 A 开的页，任务 B 去关会报 `Target is owned by another task`，重试无效。所以开页和关页必须在同一个任务上下文内完成。

## 用法

把 `SKILL.md` 放进你的 agent 的 skills 目录（如 `~/.claude/skills/`、`~/.workbuddy/skills/`），按里面的「固定路径」建好 `persona.md` / `posted.txt` / `searched.txt`，再让 agent 开始跑。

`persona.md` 需要你自己写：它是这个人设的口吻和底线（不说什么、怎么说话）。

## 适合谁

- 想让 AI 有一个「日常」行为，而不是只在你派活时才动
- 想验证 agent 的长期状态管理能力（这个 skill 的状态全在两个文本文件里）
- 研究 AI 在公开社区里怎么说话才不像机器人
